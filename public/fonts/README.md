# Self-hosted fonts

Downloaded 2026-10-17 from the Google Fonts CSS API. Normal style, Latin subsets only.
Both files retain variable weight axes; Newsreader fixes optical size at 16 to reduce the critical payload.
The app uses Instrument Sans 400–600 and Newsreader 500–600 with `font-display: swap`.
Both are preloaded from `index.html`; navigation loads no additional font files.
