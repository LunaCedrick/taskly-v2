# docs/design

Export each canvas frame as a PNG into this folder so the coding agent can look at it. Name files after the frame, lowercase with hyphens:
`sign-in`, `dashboard`, `dashboard-phone`, `project-view`, `project-view-phone`, `my-tasks`, `task-form`, `task-form-phone`,
`dialogs`, `quick-add`, `quick-add-phone`, `pickers`, `toasts`, `alerts-panel`, `menu-drawer-phone`, `search-phone`,
`filters-phone`, `states`, `states-session-not-found`, `components`.
If an image and `docs/SCREENS.md` disagree, ask the owner.
