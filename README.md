# Taskly

A fast, calm, real-time task manager: projects, tasks, and a dashboard that answers "what needs my attention today?".
React, TypeScript, Vite, Firebase, Vercel.

Status: starting Gate 0. See `docs/TRACKER.md`.

## Documents
- `docs/PLAN.md`: requirements, architecture, gates
- `docs/DESIGN.md`: calm warm tokens and components
- `docs/DECISIONS.md`: decision log and measurements
- `docs/TRACKER.md`: build progress
- `AGENTS.md` and `.agents/skills/`: instructions for the coding agent

## Setup (after Gate 0)
Copy `.env.example` to `.env`, fill in the Firebase values, then `npm install` and `npm run dev`.
